How PhishGuard works

This project uses a rule-based scoring system written in Python. It checks the text and links in a message for common phishing patterns, adds points when a warning sign is found, and then explains the result. It does not use artificial intelligence or machine learning.

PhishGuard is an educational project. A low score does not guarantee that a message is safe.
