# 🛡️ PhishGuard

PhishGuard is a phishing email analyzer built with Python and Flask. Users can paste a suspicious email or message and receive a risk score based on common phishing warning signs.

## Live Demo 
### [Try PhishGuard →](https://phishguard-1sog.onrender.com/)

## Features
- Analyzes suspicious emails and messages
- Detects common phishing warning signs
- Checks suspicious links and domains
- Gives a risk score from 0–100
- Explains why a message may be suspicious

## Built With

- Python
- Flask
- HTML & CSS
- Regular Expressions (Regex)
- GitHub
- Render

## How It Works

PhishGuard uses a rule based scoring system to look for common phishing indicators such as urgent language, requests for passwords or personal information, and suspicious URLs.

- **0–14:** Low Risk
- **15–39:** Low to Moderate Risk
- **40–69:** Suspicious
- **70–100:** High Risk

## Disclaimer

PhishGuard is an educational cybersecurity project and should not be used as a replacement for professional security tools. Avoid entering passwords, payment information, or other sensitive data.
